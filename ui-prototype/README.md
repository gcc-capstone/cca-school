# Pigeon Connect – UI Prototype (V1)

Temporary, front-end-only prototype (React + TypeScript + Bootstrap 5.3.8). No backend; all data is hardcoded and in memory, so reloading the page resets everything.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).
